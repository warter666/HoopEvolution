# 🧬 策划书 · HoopEvolution（Basketball-CSI + Evolution Engine）

> ③+④ 合体，篮球项目栈的研究型顶点 · v1 策划案 · 2026-09
> 一句话：**让 AI 在自建的篮球世界里进化战术，并用 CSI 说清楚"为什么有效"。**

```text
   进化引擎（产生战术基因组）
        │  Generate
        ▼
   回合模拟器（5v5，人盯人/联防双环境）  ← 物理标定命中模型（shotlab）
        │  Simulate & Evaluate
        ▼
   Fitness（每回合得分，双防守平均）
        │  Select / Mutate / Crossover
        └─────── 循环 G 代 ───────┐
                                  ▼
                     🕵️ CSI 解剖报告（为什么有效）
                                  ▼
                     tkinter 回放（肉眼复核解释）
```

## 1. 与前作的关系（组件复用路线的兑现）

| 前作资产 | 在本项目的角色 |
|---|---|
| shotlab 物理引擎 | 命中模型的标定源：启动时用 Monte Carlo 扫距离锚点，得出"空位命中率-距离"曲线 |
| SHOT DUEL 执行噪声 | 进攻玩家的执行噪声直接复用（σ_v0/σ_θ），防守强度=噪声放大 |
| HoopRogue 克制/意图思想 | 防守 AI 的"针对"与"轮转"行为；播报思想变身为 CSI 事件流 |
| balance.py 管线 | fitness 评估器 + 统计自检（经验总结 §一.5） |

## 2. 世界模型（MVP 范围）

* **半场 5v5**：球篮在原点，三分线 6.75 m；进攻 5 人（PG/SG/SF/PF/C），
  防守 5 人。位置型模拟（不是物理碰撞引擎），步长 0.05 s，回合上限 8 s（8 秒违例=0 分）。
* **防守两种环境**（经验总结 §一.6）：
  * 人盯人：每 0.3 s 贪心指派最近进攻者，向"持球人-球篮连线上"贴防，
    移动速度 5 m/s、反应延迟 0.25 s（延迟=空位的来源）。
  * 联防：5 个固定哨位，按球的位置摆。战术必须在两种防守下都得分，取平均。
* **掩护规则（可解释的涌现）**：无球队员经过射手防守人 0.6 m 内 →
  该防守人被"延缓"（速度 ×0.4 持续 0.8 s），记录为掩护事件。
* **执行噪声**：出手概率随"最近防守距离"调制——从物理标定曲线出发，
  受干扰时向低命中率方向偏移（复用 SHOT DUEL 的噪声思想）。

## 3. 战术基因组（可进化的"战术"）

```python
Genome = {
  routes: {player: [(x, y, t_reach), (x, y, t_reach)]},  # 每人 2 个路标点
  shooter: int,        # 谁终结
  shot_time: float,    # 何时出手（0~8s）
}
```

* **变异**：路标点抖动（±0.8 m / ±0.5 s）、shot_time 抖动、换射手、两人路线互换。
* **交叉**：按球员逐个从双亲取路线（育出"混合血统"战术）。
* **合法化**：越界坐标夹回场内，时间排序。
* 球权流：PG 发起 → 每当持球人到达路标点，把球传给"当前空位分最高"的队友
  （传球事件入库）→ shot_time 时若球在手则终结，否则补一次传给射手。

## 4. 进化引擎

* 种群 24 · 精英 4 · 锦标赛选择 · 变异率 0.7 · 交叉率 0.5 · 默认 12 代。
* **fitness = 人盯人 × 8 回合 + 联防 × 8 回合 的每回合平均得分（ppp）**；
  同分时以方差小者胜（稳定性也是战术质量）。
* 每代输出（终端）：

```text
Gen 07 · best 1.082 ppp · avg 0.731 · 多样性 0.41
  TACTIC #0183  射手 SG · shot 4.9s · 掩护 3.2 次/回合
```

## 5. 🕵️ CSI 解剖报告（本项目的灵魂，经验总结 §一.1/§三.2）

对冠军战术跑 24 个回合，输出数据驱动的"为什么有效"：

```text
═══ CSI · TACTIC #0183 解剖报告 ═══
样本 24 回合 · 命中率 61% · ppp 1.28 · 人盯人 1.35 / 联防 1.21

为什么有效：
• 射手终结点分布: 弧顶 12 / 左底角 3 / 右底角 9，平均防守距离 2.31 m
• 掩护 3.4 次/回合，63% 集中在出手前 1.5 s → 出手瞬间防守人被延缓 0.42 s
• 平均传球 2.1 次 → 防守轮转总位移 4.8 m/回合（消耗）
• 38% 回合 C 在篮下 1.8 m 内停留 >1.5 s，吸引协防后外弹

代表性回合（tkinter 可回放同一事件流）：
t=0.0  PG(−3.0, 8.0) 发起
t=1.6  PF 路经 SG 防守人 0.4 m → 掩护成立（延缓 0.8 s）
t=2.4  传球 PG → SG（空位分 0.71）
t=4.9  SG 右底角出手 5.9 m · 最近防守 2.6 m · 命中概率 0.48 ✓
```

**约束**：报告里每个数字都可由事件流复算；回放动画与报告读同一份事件日志
（解释与肉眼可见的东西一致）。

## 6. 命中模型标定（物理即底座）

启动时（若无缓存）用 shotlab 引擎对 6 个距离锚点
[2, 3.5, 5, 6.5, 7.5, 9] m 各跑 120 次带执行噪声的蒙特卡洛 →
"空位命中率-距离"曲线；shotlab 不可用时退化为文献表并**在日志显式声明**。
比赛时按 `p = p_base(dist) × clamp(0.6 + 0.22×防守距离, 0.6, 1.2)` 调制。

## 7. 里程碑

- **M1（本次）**：球场/基因组/回合模拟器/双防守环境/进化引擎/CSI 报告/
  ASCII 战术图 + tkinter 回放/CLI（evolve · show · gui）/ 测试。
- **M2**：防守也进化（攻防协同进化，军备竞赛）；战术基因加入传球目标策略；
  多种群孤岛模型 + 迁移；进化结果持久化（白名单目录）。
- **M3**：接入真实比赛数据（CBS 解析真实回合 → 提取"战术指纹"）；
  与 HoopRogue 打通——进化出的战术变成战术板里的新战术卡（确定性效果）。

## 8. 风险

| 风险 | 对策 |
|---|---|
| 进化朝测量噪声方向优化（小样本 ppp 抖动） | fitness 用 2×8 回合平均；精英保留；CSI 报告附样本量 |
| 位置型模拟太"假" | 防守反应延迟 + 掩护延缓规则制造真实空位动态；回放肉眼校验 |
| shotlab 跨仓库导入 | 相对路径引导 + 文献表回退（显式声明） |
| 评估太慢 | 回合早停（得分/违例即停）；MVP 24×12 代控制在 ~1 分钟 |
