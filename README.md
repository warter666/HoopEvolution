# HoopEvolution

让 AI 在自建的篮球世界里进化战术，并用 CSI 说清楚"为什么有效"。
这是篮球项目栈的研究型顶点：③ Basketball-CSI 与 ④ Evolution 的合体。

## 它的流水线

```
进化引擎(战术基因组) -> 回合模拟器(5v5) -> fitness(双防守平均ppp)
        ^                                        |
        └────── 选择/交叉/变异 <──── 记分 <──────┘
                                                 v
                          CSI 解剖报告(为什么有效) + tkinter 回放
```

四个值得一说的设计决定：

1. **命中模型是标定出来的，不是编的。** 启动时跨仓库调用 shotlab 物理引擎，
   对 6 个距离锚点各跑 120 次蒙特卡洛，得出"空位命中率-距离"曲线；
   shotlab 缺席时退化为文献表并显式声明来源。
2. **战术必须在两种防守下得分。** 人盯人有反应延迟（空位的物理来源），
   联防哨位随球滑动。fitness 取两者平均，防止进化出只会打一种防守的偏科战术。
3. **优势必须可解释。** 无球人贴近射手的防守人 0.6 米内，掩护成立、防守人被
   延缓 0.8 秒——进化找到的每个长处都能被事件流讲出来。
4. **解释可以被肉眼复核。** CSI 报告与 tkinter 回放读同一份事件流。

## 运行

```bash
python -m hoopevo evolve --gens 12 --pop 24   # 完整进化 + 冠军 CSI 报告
python -m hoopevo show                        # 快速进化 + 解剖报告
python -m hoopevo replay                      # 进化冠军 + 回放动画
python -m unittest discover -s tests          # 13 个测试
```

## 一次真实的输出

进化 10 代后，冠军战术把射手摆在弧顶、PF 上前掩护，专打联防外线软肋
（对联防 3.00 ppp，对人盯人 1.12）。CSI 报告节选：

```
样本 24 回合 · 命中率 54% · ppp 1.62 · 人盯人 1.25 / 联防 2.00
为什么有效：
* 射手终结点: 弧顶 24（平均出手 9.1 m，平均防守距离 2.41 m）
* 掩护 1.5 次/回合（被延缓的防守人给射手制造出手空间）
  t= 0.9  C 掩护成立：PF 的防守人被延缓 0.8s
  t= 5.5  PF 弧顶出手 9.1 m · 最近防守 0.9 m · 命中概率 0.41 -> 命中
```

## 已知局限

联防偏软（外线防守距离调制顶满），冠军会集中打它——真实但不平衡，
下一步是让防守也进化（攻防军备竞赛）。命中曲线 120 样本有约 ±5% 抽样噪声。
进化结果暂只输出到 stdout。
